## 🚀 Step-by-Step: How to Push & Host to GitHub

### Step 1: Create a Repository on GitHub
1. Open [GitHub](https://github.com/new) and log in to your account (`@TufyalAhmmed`).
2. Create a new repository:
   - **Recommended Option A (User site):** Set Repository Name to `tufyalahmmed.github.io` (Public). This will make your URL clean: `https://tufyalahmmed.github.io`.
   - **Option B (Project site):** Set Repository Name to `Portfolio` (Public). Your URL will be: `https://tufyalahmmed.github.io/Portfolio`.
3. Do **not** check "Add a README" or ".gitignore" (these are already configured in this repo).
4. Click **Create repository**.

### Step 2: Push Your Local Code to GitHub
Open your terminal in this directory (`/Users/tufyalahmmed/Documents/Portfolio`) and run:

```bash
# Add all files to git
git add .

# Create the initial commit
git commit -m "feat: initial gentle & professional portfolio release"

# Ensure main branch is selected
git branch -M main

# Link your remote GitHub repository (replace with your repo URL)
git remote add origin https://github.com/TufyalAhmmed/Portfolio.git
# (or git remote add origin https://github.com/TufyalAhmmed/tufyalahmmed.github.io.git)

# Push to GitHub
git push -u origin main
```

### Step 3: Enable GitHub Pages
1. In your GitHub repository, go to **Settings** > **Pages** (under the "Code and automation" section in the left sidebar).
2. Under **Build and deployment**:
   - **Source**: Select `Deploy from a branch`.
   - **Branch**: Select `main` and folder `/ (root)`.
3. Click **Save**.
4. Wait 1–2 minutes; GitHub Pages will deploy and give you your active live link!
